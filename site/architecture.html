How the Liquidware & AVD Repos Fit Together

Four Liquidware repositories divide the work cleanly between open-source knowledge and Azure deployment on one side, and private assessment and packaging automation on the other—plugging directly into the avd-ops Azure Virtual Desktop foundation.

The Layers

Read from the bottom up: the AVD landing zone provides the cloud-native foundation, avd-liquidware deploys the optional Liquidware tier into Azure, ux-assess and flexapp-factory automate data analysis and application packaging, and liquidware-ninja holds the shared second brain, schemas, and guardrails for all of them.

Second Brain, Templates & Guardrails (Public · MIT / Apache-2.0)

Shared knowledge & toolkit: liquidware-ninja

Owns the 2ndbrain knowledge base (docs/knowledge/), reference guardrails (templates/), technical field notes (blog/), and pure PowerShell validation functions (LiquidwareNinja.psm1) consumed across every repo below.

Private Companion Engines (High-Level Architecture Overview)

Assess & report: ux-assess Private

Pulls Stratusphere UX /lwl/api telemetry, checks collection health, normalizes and HMAC-pseudonymizes five canonical tables, scores SpotCheck findings, and generates .xlsx, .pdf, .pptx, and Git-backed Power BI .pbip deliverables.

Evaluate & package: flexapp-factory Private

Evaluates existing application servers, joins ux-assess usage data, builds dependency DAGs, converts legacy packages (.appv, .msix, .intunewin, PSADT), and drives unattended FlexApp captures and smoke tests.

Azure & AVD Execution Tier (Public · MIT)

Liquidware in Azure: avd-liquidware

Subscription-scoped Bicep and PowerShell for Stratusphere UX appliances, CID Key rollout, ProfileUnity console/shares, and FlexApp App Attach registration.

AVD Foundation: avd-landing-zone

Entra ID-joined, Intune-managed, private-by-default Azure Virtual Desktop landing zone with FSLogix on Premium Azure Files.

AVD Verification & Design: avd-current-state & avd-assess

Read-only collector for deployed AVD estates and the target-state sizing/design methodology.

Desktop Estate (AVD, Windows 365, Citrix CVAD/DaaS, Omnissa Horizon, Windows Server RDS, Physical PCs)monitored by Stratusphere CID Keys · managed by ProfileUnity & FSLogix · layered with FlexApp · supported by CommandCTRL
