The Liquidware Repositories

Our Liquidware engineering work is split into four focused repositories—two open-source repositories on GitHub and two private companion engines documented here at a high level.

liquidware-ninja

Public · MIT

Second Brain, Templates & PowerShell Toolkit

The authoritative knowledge base and general catchall repository across Stratusphere UX, ProfileUnity, FlexApp, and CommandCTRL.

  • 2ndbrain Knowledge Base (docs/knowledge/): 21 curated topic pages, MADR decision records, known errors, and weekly upstream digests.
  • Reference Templates (templates/): FSLogix Portability coexistence guardrails, FlexApp package manifests, Stratusphere Inspector catalogs, and CommandCTRL multi-session baselines.
  • PowerShell Toolkit (scripts/tools/): LiquidwareNinja.psm1 (9 offline-testable functions) and Test-LwCidKeyHealth.ps1 (PS 5.1/7+ endpoint agent health check).

avd-liquidware

Public · MIT

Azure & AVD Deployment Tier

Automates deploying and operating the optional Liquidware tier in Azure against an existing avd-landing-zone estate while keeping FSLogix as the primary profile container.

  • Stratusphere UX in Azure (stratusphere/): Preflight checks, Marketplace Hub/Database/Collector appliance deployment, Connector ID Key rollout via Run Command, and safe teardown.
  • ProfileUnity & FlexApp Tier (profileunity/): Spoke VNet peering, Private DNS links, Key Vault, lwconfig / portability / appattach Premium Azure Files shares with Entra Kerberos (no storage keys), and Console VM.
  • Two-Step Promotion: Managed Identity blob staging to on-demand ACI file-share promotion and operator-registered AVD App Attach.

ux-assess

Private Repo

Stratusphere UX Assessment & Deliverable Pipeline

Automates the end-to-end data engineering and reporting work of a Stratusphere UX engagement across physical PCs, Citrix, Omnissa Horizon, RDS, AVD, and Windows 365.

  • Collection & Health: Pulls business-hour sliced data from /lwl/api (or Inspector exports) and verifies active collection coverage against expected inventory.
  • Normalization & Privacy: Maps Hub columns into five canonical tables and applies deterministic keyed HMAC-SHA256 pseudonymization so before/after migration baselines align without exposing PII.
  • Multi-Format Deliverables: Scores platform-aware SpotCheck thresholds, classifies apps for Base Image vs. FlexApp, and renders .xlsx, .pdf, .pptx, and a Git-backed Power BI Project (.pbip TMDL/PBIR).

flexapp-factory

Private Repo

Application Server Evaluator & Unattended Packaging Factory

Inspects legacy application servers, joins usage telemetry, and orchestrates deterministic, unattended Liquidware FlexApp packaging and validation pipelines.

  • Server Evaluation & Dependency DAG: Inspects registry uninstall keys, MSI tables, services, kernel drivers (.sys), COM classes, and ODBC DSNs; joins ux-assess usage data; classifies apps into 3 tiers and groups composite recipes.
  • 4-Step Installer Sourcing Cascade: Resolves media across customer shares, curated recipes + Winget/Evergreen, full-CAB cached MSIs, or emits a Missing Media Checklist.
  • Unattended Capture & Smoke Testing: Converts .appv, .msix, .intunewin, and PSADT bundles into a deterministic build-queue.json, drives Single-VM CLI or Batch FPA REST APIs, and emits validated liquidware-ninja-flexapp-package/v1 manifests.

Quick Start in Azure Cloud Shell

Clone liquidware-ninja in Azure Cloud Shell (or locally in PowerShell 7+) to run the offline guardrail functions or query the knowledge base:

if (-not (Test-Path ~/liquidware-ninja)) { git clone https://github.com/nickprignano/liquidware-ninja.git ~/liquidware-ninja }
Set-Location ~/liquidware-ninja; git checkout -q main; git pull -q --ff-only
Import-Module ./scripts/tools/LiquidwareNinja.psm1 -Force
Get-LwSpotCheckThreshold
Test-LwPortabilityOverlap -PortabilityPath @('%APPDATA%\Notepad++', '%LOCALAPPDATA%\Contoso\App') -EnabledModule @('Portability')

Guardrails & Contributing

  • Zero Tenant or Customer DataNothing in any public repo identifies a real tenant, subscription, employer, or customer. Examples use contoso.com, 10.60.x.x, and all-zero GUIDs.
  • No Vendor Binaries or LicensesBring your own Liquidware licenses and download appliances or installers from your own Hub or Azure Marketplace.
  • Evidence & Guards FirstEvery rule in the knowledge base traces to a primary source or lab run, and every PowerShell utility is backed by offline Pester tests.
  • Open Knowledge BaseContributions, forks, and field reports on the public repos are welcome under the MIT License.
