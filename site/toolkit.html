PowerShell Toolkit & Reference Templates

liquidware-ninja ships a cross-platform PowerShell module (scripts/tools/LiquidwareNinja.psm1), an endpoint diagnostic script for the Stratusphere Connector ID Key (Test-LwCidKeyHealth.ps1), and five reference JSON templates (templates/)—all tested offline with Pester 5.

Module Functions (LiquidwareNinja.psm1)

FunctionProductWhat It Validates or Builds
Test-LwPortabilityOverlapProfileUnity + FSLogixAudits candidate Portability paths and enabled modules against templates/profileunity/fslogix-portability-guardrails.json to block FSLogix double-persistence and forbidden full-profile disk modules (ProfileDisk, VhdProfile).
Export-LwPortabilityRulesetProfileUnity + FSLogixFilters candidate Portability paths to strip any direct or child overlap with fslogixOwnedPaths and emits a clean liquidware-ninja-portability-ruleset/v1 object.
Compare-LwProfileUnityConfigProfileUnityDiffs two ProfileUnity configuration exports (sample-config-export.json shape) and reports added/removed modules, Portability paths, application restrictions, and iniSha256 digest changes before promotion.
Test-LwFlexAppCandidateFlexApp + StratusphereScores an application for BaseImage (>80% user share), FlexAppAppAttach, FlexAppOne (offline required), VersionConsolidationFirst (>3 versions), or NotRecommendedForLayering (kernel drivers/boot services).
New-LwFlexAppManifestFlexAppBuilds and validates a liquidware-ninja-flexapp-package/v1 metadata manifest, enforcing 64-char hex SHA-256 digests and the Single Assignment System Rule.
Get-LwAssignmentConflictFlexApp + AVDDetects applications simultaneously assigned in more than one delivery plane (AvdAppAttach, ProfileUnityFlexApp, NativeMsix).
Get-LwSpotCheckThresholdStratusphere UXReturns canonical Liquidware SpotCheck thresholds and their sources from templates/stratusphere/inspector-catalog.json, optionally filtered by metric name.
ConvertTo-LwApiUrlStratusphere UXConstructs URL-encoded https://<hub>/lwl/api?json=... Inspector queries with explicit date ranges and business-hour slices (StartTime / EndTime).
Test-LwCommandCtrlBaselineCommandCTRLValidates a CommandCTRL endpoint configuration against templates/commandctrl/multisession-baseline.json (user consent, privacy exclusions, sampling interval, and Stratusphere coexistence).

Endpoint Health Check (Test-LwCidKeyHealth.ps1)

Runs on both Windows PowerShell 5.1 and PowerShell 7+ to verify three things when a desktop or session host is missing from the Stratusphere Hub:

  1. Installation directory & certificate bootstrap: Checks C:\Program Files (x86)\Liquidware Labs\Connector ID and inspects ca\public\mgrcert.pem / ca\cert.txt.
  2. Agent service state: Verifies that tntgrd or LwL.ConnectorID is installed and Running.
  3. Hub callback reachability: Tests TCP 443 connectivity from the endpoint to the Hub or Collector address.
