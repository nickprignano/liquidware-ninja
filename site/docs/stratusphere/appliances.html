Stratusphere UX appliances in Azure

verifiedReviewed 2026-10-29Source: stratusphere/appliances.md

Stratusphere UX runs as Linux appliances from Azure Marketplace. This repo deploys them with Deploy-Stratusphere.ps1; this page holds the facts behind it, checked against Liquidware's 6.7.1 documentation. None of it has been through a lab run on a real subscription yet.

Sources: UX prerequisites, Installing on Microsoft Azure, Using the Database appliance.

Roles

Role When Size used here Notes
Hub Always Standard_D4s_v5, 128 GB Premium SSD Liquidware's minimum: 4 vCPU, 16 GB RAM, 60 GB disk
Database Above about 1,000 devices at the default 60-minute callback, or more than 1,000 callbacks an hour Standard_D4s_v5, 256 GB Minimum 4 vCPU, 16 GB RAM, 94 GB disk. Trust is established, then the Hub is joined to it from the Hub's console
Collector Optional: CID Data Collector (spreads callback load, or takes callbacks the Hub can't), or Network Collector Standard_D2s_v5, 64 GB Minimum 2 vCPU, 8 GB RAM, 22 GB disk. Each one is added and registered in the Hub's Collector Administration

Liquidware sizes real deployments with its online Stratusphere Sizing Guide, recommends keeping the Hub, Database and Collectors close (a proximity placement group, ideally the same host group), and offers Standard_D4s_v3 as the Hub's default size in the Marketplace flow.

  • Each role has its own Marketplace plan (Hub, Database, Collector); see azure/marketplace.md.
  • A VM's Marketplace plan can't change after it's created, so changing role or plan means a new VM.

Credentials

  • The administrator account Azure sets at creation is the appliance's SSH login. Liquidware's Azure guide recommends an SSH public key and supports a password.
  • The web console has its own account: ssadmin, with Liquidware's documented default password until you change it (on AWS the default is the instance ID). Change it at first sign-in; it's a different credential from the Azure one.
  • An appliance keeps the password it was created with, so a rerun has to reuse it. This repo generates it once and keeps it in Key Vault (decision 0006).

Licensing

Bring your own Stratusphere license (the Marketplace Hub is BYOL). Liquidware offers evaluation licenses; their size and length come with the evaluation, not from the public docs (licensing FAQs). After a license change, the API can return "License Not Authorized" until the Hub is rebooted (support article). No license material belongs in the repo (decision 0004).

First-time setup

The Hub's license, API user and API allow list are set in its web console. See hub-setup.md.
