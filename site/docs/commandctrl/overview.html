CommandCTRL overview and real-time support

verifiedReviewed 2026-10-29Source: commandctrl/overview.md

Liquidware CommandCTRL is a cloud-hosted (SaaS) real-time endpoint monitoring, diagnostic, and remote support tool for virtual and physical desktops, with a history playback of up to 30 days (general availability announcement). While Stratusphere UX focuses on historical trend collection, SpotCheck assessments, right-sizing, and estate-wide baselining, CommandCTRL focuses on live helpdesk triage and remediation.

Stratusphere UX vs. CommandCTRL

Question Tool Why
"How should we size our AVD host pools based on the last 14 days of peak business hours?" Stratusphere UX Collects historical inspector time-series across the estate for SpotCheck analysis and sizing (ux-assess)
"Did our migration from Citrix to AVD improve p95 logon times and CPU queue length?" Stratusphere UX Before/after baseline comparison (baseline.json) across assessment windows
"A user is having high latency and a frozen app right now—what process or network hop is causing it, and can I fix it live?" CommandCTRL Real-time process, network, GPU and protocol telemetry, remote shell, and remediation actions (kill a process, stop or restart a service, run a script)

Architecture notes

  • Control plane: SaaS-delivered by Liquidware (no on-premises or customer-hosted Hub appliance to deploy, unlike Stratusphere UX).
  • Endpoint agent: Windows, macOS, Linux and thin-client (IGEL, eLux) agents; they talk outbound over HTTPS (TCP 443) to *.cc.liquidware.com (cc, func and ws-broker if listed one by one) (support article, agent install guides).
  • Security and governance in Azure estates: Because CommandCTRL includes live remote shell and process termination capabilities, treat its agent and operator roles with the same change-control and audit guardrails as privileged administrative access (Phase L3 in avd-liquidware docs/spec.md).
