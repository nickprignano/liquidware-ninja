avd-liquidware

Automation for running Liquidware products in Azure: Stratusphere UX for assessments, and an optional tier for Azure Virtual Desktop (ProfileUnity for profile portability and UEM, FlexApp packages through AVD App Attach, and CommandCTRL for support) deployed against an existing avd-landing-zone estate while keeping FSLogix as the primary profile container.

Public · MITBicep (AVM)PowerShellAzure Cloud ShellEntra Kerberos

What It Does

  • Stratusphere UX in Azure (stratusphere/): Subscription/network preflight checks, Azure Marketplace Hub, Database, and Collector appliance deployment, Connector ID Key rollout across session hosts via Azure Run Command, and safe teardown that enforces the family's never delete the last copy rule.
  • ProfileUnity & FlexApp Tier in Bicep (profileunity/bicep/main.bicep): Subscription-scoped Bicep deploying rg-<base>-liquidware, spoke VNet peering, Private DNS zone links, Key Vault, Premium Azure Files shares (lwconfig, portability, appattach) with allowSharedKeyAccess: false and Entra Kerberos, and the ProfileUnity Management Console VM.
  • Two-Step Configuration Promotion & App Attach Registration (scripts/): Deploy-LiquidwareTier.ps1, Managed Identity blob staging to on-demand ACI file-share promotion, and operator-registered AVD App Attach without storing standing Entra client secrets on the console VM.
  • Red-Teamed Specifications (docs/): Detailed architecture specifications (docs/spec.md and docs/deploy-spec.md) defining product ownership boundaries, RBAC per path, cost controls, and security reviews.
