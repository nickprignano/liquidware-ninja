liquidware-ninja

The Liquidware second brain and general catchall repository: a living knowledge base, architecture reference, technical blog, template library, and utility toolkit for running Stratusphere UX, ProfileUnity, FlexApp, and CommandCTRL across virtual and physical desktops.

Public · MIT / Apache-2.02ndbrain KBPowerShell 7Pester 5Cloudflare Workers

What It Does

  • Living 2ndbrain Knowledge Base (docs/knowledge/): Curated topic pages across all four Liquidware products and six desktop platforms (AVD, Windows 365, Citrix, Omnissa Horizon, RDS, physical PCs), MADR decision records, known-error catalog, and automated weekly upstream digests.
  • Technical Blog & Field Notes (blog/): Deep-dive engineering write-ups covering Entra-only AVD without storage keys, Stratusphere UX SpotCheck to git-backed Power BI PBIP/TMDL pipelines, and Windows Server RDS to Windows 11 multi-session Portability migrations.
  • Reference Templates (templates/): FSLogix Portability coexistence guardrails, ProfileUnity plain-text configuration exports, FlexApp package manifests, Stratusphere Inspector catalogs, and CommandCTRL multi-session security/privacy baselines.
  • Cross-Platform PowerShell Toolkit (scripts/tools/): Nine pure, offline-testable validation and builder functions in LiquidwareNinja.psm1 plus Test-LwCidKeyHealth.ps1 for Windows PowerShell 5.1 and PowerShell 7+ endpoints.
